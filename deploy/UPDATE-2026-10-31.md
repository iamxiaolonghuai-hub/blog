# 2026-10-31 博客更新包

本包包含当前前后端源码、数据库迁移和已构建的前端 `dist/`。旧的 `blog-bundle.tar.gz` / `blog-image.tar.gz` 不包含本次修改，请勿用于更新。

## 在云服务器更新

1. 先备份现有数据库和 `/opt/blog/deploy/.env`，并确认服务器能够访问 Docker Hub。
2. 将本包上传到服务器，在 `/opt/blog` 解压。不要覆盖服务器已有的 `deploy/.env`。
3. 在现有 `blog` 数据库执行 `db/migrations/20261031_site_settings.sql`。该迁移可重复执行，不改动现有文章。
4. 在 `/opt/blog` 运行：

   ```bash
   docker build -t blog:latest .
   docker compose -f deploy/docker-compose.prod.yml up -d --no-deps backend nginx
   ```

5. 验证 `/api/site`、`/api/posts` 和后台“站点资料”保存接口。若部署使用了 `deploy/with-db.yml`，更新时在上述 `docker compose` 命令后追加 `-f deploy/with-db.yml`（放在 `up` 前）。

注意：文章和站点资料存在数据库中，本包不包含本地数据库数据。云服务器原有文章不会因代码包自动改变；新建文章需在后台导入或发布。
