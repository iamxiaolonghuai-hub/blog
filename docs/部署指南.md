# 博客上云部署指南（腾讯云）

> 可上传预先打包的 Docker 镜像，也可直接从 GitHub 克隆源码；没有镜像包时部署脚本会自动构建。
> **服务器上不需要安装任何编译器**，只要能跑 Docker 即可。

---

## 你要准备的三样东西

本地项目根目录下已有：

| 文件                   | 大小    | 说明                                                |
| -------------------- | ----- | ------------------------------------------------- |
| `blog-bundle.tar.gz` | 272MB | **推荐**。含全部 3 个镜像（blog + mysql + nginx），服务器不用联网拉镜像 |
| `blog-image.tar.gz`  | 31MB  | 轻量包，只含 blog 镜像，其余靠服务器现场 `docker pull`（国内可能慢）      |
| `db/schema.sql`      | —     | 首次启动自动建库建表 + 初始管理员账号                              |
| `deploy/`            | —     | 编排文件、`nginx.conf`、`setup.sh`、`.env.example`       |

其中 deploy 目录里的编排文件：

| 文件                        | 作用                                        |
| ------------------------- | ----------------------------------------- |
| `docker-compose.prod.yml` | 主编排：后端 + Nginx（**不含数据库**，连哪个库由 `.env` 决定） |
| `mysql-standalone.yml`    | 独立共享 MySQL 实例，多项目共用（**推荐**）               |
| `with-db.yml`             | 叠加文件，让主编排自带一个 MySQL                       |
| `upload.sh` / `setup.sh`  | 本地一键上传 / 服务器一键部署                          |

服务器上最终目录结构（**必须保持一致**，compose 里用了相对路径）：

```
/opt/blog/
├── blog-bundle.tar.gz
├── db/
│   └── schema.sql
└── deploy/
    ├── docker-compose.prod.yml
    ├── nginx.conf
    └── setup.sh        # 执行后自动生成 .env
```

## 第 0 步：选数据库方案（重要）

数据库有三种放法，**推荐第 1 种**：

| 方案                      | 命令/配置                                 | 优点                                   | 适合场景        |
| ----------------------- | ------------------------------------- | ------------------------------------ | ----------- |
| **① 独立共享 MySQL 容器**（推荐） | `mysql-standalone.yml`，容器名 `db-mysql` | 多项目共用省内存；更新博客 `down` 不会停数据库；备份调优只动一处 | 一台服务器跑多个项目  |
| ② compose 自带 MySQL      | `prod.yml` + `with-db.yml`            | 一条命令全带走，最简单                          | 只跑这一个博客     |
| ③ 腾讯云托管 TencentDB       | `.env` 里 `DB_HOST` 填内网地址              | 自动备份、高可用、不用自己运维（约 ¥30/月起）            | 生产正式站点、数据重要 |

**连法本质都一样**：给后端 5 个环境变量，三种方案只差 `DB_HOST`：

```ini
DB_HOST=db-mysql                        # ① 独立容器：填容器名
DB_HOST=mysql                           # ② 自带：填 compose 服务名
DB_HOST=xxxxxx.mysql.tencentcdb.com     # ③ 腾讯云托管：填内网地址（不要用公网地址）
DB_PORT=3306
DB_NAME=blog
DB_USER=blog
DB_PASSWORD=...
```



> ⚠️ 安全红线：**永远不要把 3306 端口映射到公网**。容器间通信走 Docker 网络（`blog-shared`），
> 本地要管理数据库时用 SSH 隧道：`ssh -L 3306:127.0.0.1:3306 root@服务器`

### 其他项目怎么共用这个数据库

在另一个项目的 compose 里加入同一个网络，容器名即主机名：

```yaml
services:
  myapp:
    networks: [blog-shared]
    environment:
      DB_HOST: db-mysql        # Docker 内部 DNS 自动解析
      DB_PASSWORD: xxx
networks:
  blog-shared:
    external: true             # 网络已在博客那边创建好
```

为新项目建库建账号，一条命令（会自动打印连接串）：

```bash
./db/create-database.sh myapp          # 库名 myapp，账号同名，随机密码
```

## 第 1 步：腾讯云控制台放行端口

> 不做这步，部署完外网访问会一直转圈超时。

- **轻量应用服务器**：控制台 → 服务器 → 点击实例 → **防火墙** → 添加规则
  - 应用类型：HTTP(80)，来源：全部 IPv4
  - 再加一条 TCP:22（一般默认已有，用于 SSH）
- **云服务器 CVM**：控制台 → **安全组** → 实例所属安全组 → 入站规则 → 添加 `TCP:80`，来源 `0.0.0.0/0`

同时记下服务器的**公网 IP**。

## 第 3 步：服务器上一键部署

```bash
ssh root@你的公网IP

cd /opt/blog
chmod +x deploy/setup.sh
./deploy/setup.sh
```

脚本会自动完成：装 Docker → 加载镜像 → 生成随机密码 `deploy/.env` →**让你选数据库方式**→ 启动容器 → 等待就绪 → 自检打印结果。

```
选择数据库的部署方式：
  1) 独立共享 MySQL 容器    推荐 · 多项目共用 · 更新博客不影响数据库
  2) compose 自带 MySQL     简单 · 单项目自包含
  3) 腾讯云托管 TencentDB   已购实例 · 自动备份高可用
请输入 1/2/3 [默认 1]:
```

不想交互也可以先在服务器上写好 `deploy/.env` 里的 `DB_MODE=standalone`（或 `withdb` / `manageddb`）。

看到下面的输出就是成功了：

```
================ 部署完成 ================
  前台首页      http://1.2.3.4/
  后台登录      http://1.2.3.4/admin/login
  管理员账号    使用首次部署时设置的用户名和密码
=========================================
接口自检：
  /            200

```

> MySQL 首次启动会自动执行 `db/schema.sql` 建表；部署脚本随后会提示设置管理员用户名和密码。已有管理员时不会覆盖。

### 手动部署（不用 setup.sh 时）

方案 ① 独立共享数据库：

```bash
cd /opt/blog
cp deploy/.env.example deploy/.env && vi deploy/.env    # 填 JWT 密钥 + 数据库密码
docker compose -f deploy/mysql-standalone.yml up -d     # 先起数据库，等它 healthy
docker compose -f deploy/docker-compose.prod.yml up -d  # 再起博客
sudo bash deploy/init-admin.sh                             # 首次设置管理员
```

方案 ② compose 自带：

```bash
docker compose -f deploy/docker-compose.prod.yml -f deploy/with-db.yml up -d
sudo bash deploy/init-admin.sh
```

方案 ③ 腾讯云托管：在 TencentDB 控制台建好实例和 `blog` 库，把内网地址填进 `.env` 的 `DB_HOST`，然后：

```bash
docker compose -f deploy/docker-compose.prod.yml up -d
sudo bash deploy/init-admin.sh
```

> 托管数据库不会自动执行 `db/schema.sql`，首次要手动导一次：
>
> ```bash
> docker run --rm -i -v /opt/blog/db:/sql mysql:8.0 \
>   sh -c "exec mysql -h'内网地址' -u'账号' -p'密码' blog" < /opt/blog/db/schema.sql
> ```

## 第 4 步：设置管理员

`deploy/setup.sh` 会在首次部署时提示设置管理员账号和密码。手动部署时运行 `sudo bash deploy/init-admin.sh`。密码至少 8 位，仅 bcrypt 哈希写入数据库；已有管理员时脚本不会修改现有账号。非交互部署可临时提供 `ADMIN_USERNAME` 与 `ADMIN_PASSWORD` 环境变量，不要写进仓库或 `deploy/.env`。

## 常用运维命令

```bash
cd /opt/blog
docker compose -f deploy/docker-compose.prod.yml ps               # 查看博客容器
docker compose -f deploy/docker-compose.prod.yml logs -f backend  # 看后端日志
docker compose -f deploy/docker-compose.prod.yml up -d            # 启动/重启博客
docker compose -f deploy/docker-compose.prod.yml down             # 只停博客（数据库不受影响）

# 独立数据库单独管理
docker compose -f deploy/mysql-standalone.yml ps
docker compose -f deploy/mysql-standalone.yml logs -f
docker compose -f deploy/mysql-standalone.yml restart

# 备份整个 blog 库
docker exec db-mysql mysqldump -uroot -p"$(grep MYSQL_ROOT_PASSWORD deploy/.env | cut -d= -f2)" blog > blog-$(date +%F).sql
```

**数据都在 Docker 卷里**（`db_mysql_data` 数据库、`blog_uploads` 上传的图片），重启 / `down` 都不会丢。
只有 `docker compose ... down -v` 才会删卷，慎用。

### 给其他项目开库

```bash
./db/create-database.sh myapp                # 建库 + 建独立账号 + 打印连接串
```

## 以后更新博客版本

重新在本地构建镜像 → 导出 → 上传 → 服务器上：

```bash
docker compose -f deploy/docker-compose.prod.yml down
docker load < blog-bundle.tar.gz
docker compose -f deploy/docker-compose.prod.yml up -d
```

## 常见问题

| 现象                                                                   | 原因 / 解决                                                                                                |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 外网访问超时                                                               | 腾讯云防火墙没放行 80（第 1 步）                                                                                    |
| `Permission denied (publickey)`                                      | 腾讯云默认禁用密码登录？用控制台「重置密码」后重试，或改用秘钥登录                                                                      |
| 后端起不来，`No database is supported`                                     | 镜像加载不完整，重新 `docker load < blog-bundle.tar.gz`                                                          |
| 后端日志 `Access denied for user 'blog'`                                 | `.env` 里 `DB_PASSWORD` 与数据库里账号密码不一致；独立容器模式下要和运行 `mysql-standalone.yml` 时用的 `MYSQL_PASSWORD` 一致         |
| 后端日志 `Unknown MySQL server host 'db-mysql'`                          | 两者不在同一个网络：确认 `mysql-standalone.yml` 已启动创建了 `blog-shared` 网络                                            |
| `network blog-shared is declared as external but could not be found` | 网络还没建，先 `docker compose -f deploy/mysql-standalone.yml up -d` 再起博客                                     |
| 页面能开但接口 502                                                          | 后端还没就绪，等 30 秒；或 `docker logs blog-backend` 看具体报错                                                       |
| 中文又变 `???`                                                           | 检查 `docker exec db-mysql mysql -uroot -p -e "SHOW VARIABLES LIKE 'character_set_server'"` 应为 utf8mb4   |
| MySQL 容器反复重启                                                         | 服务器内存太小（<1G），MySQL 8 至少需要 1G；`mysql-standalone.yml` 里已限制 `innodb-buffer-pool-size=256M`，2G 机器建议再加 swap |

## 进阶（可选）

- **绑域名**：域名解析 A 记录指向服务器 IP，然后改 `deploy/nginx.conf` 里的 `server_name`
- **上 HTTPS**：容器外加一层 Caddy（自动签发证书），或 `certbot` 签证书后挂进 Nginx
- **不放 22 端口到公网**：改用腾讯云「密钥登录」并在防火墙里限制来源 IP
